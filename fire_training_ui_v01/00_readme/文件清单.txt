==================================================
五、接入备注（程序侧）
==================================================

1. 所有底板、按钮、图标、印章、指示灯、手柄 PNG 均为 32bpp ARGB，物件外背景
   alpha=0；纸张内部不透明，可直接叠在场景/HUD 上。效果图与概念图为不透明位图。
2. 底板与按钮均不含文字、数字、字母；标题、正文、按钮文案、数值、状态符号全部
   由程序用 TMP 叠加（沿用工程现有 NotoSansCJKsc 字体）。
3. 按钮四态为同一造型的视觉变体；导入后在 Unity 中对齐同一锚点与透明边距，避免
   状态切换跳动。点击区域由程序配置，装饰突出部分不等于点击区。
4. 导出像素为建议尺寸的放大版，导入时按 Brief 建议尺寸压缩：
   横按钮 512×160、方形按钮 256×256、图标 256×256、指示灯 128×128、
   印章 512×512、面板 1536×1024 / 1920×1280。不要非等比拉伸。
5. 效果图内示范文字（标题、按钮文案、说明句、03:25、68/100）为 AI 排版示意，
   个别字形可能不准；正式文案以工程现有中英文案为准。
6. 地图底图（map_frame）只给外框与留白；真实路线、房号、楼层、玩家位置、出口
   标记由程序依据 Unity 场景绘制，不要把效果图里的房间布局当成最终地图。
7. 手柄底图与高亮 overlay 仅作教学示意：overlay 形状层与底图非像素级对齐，位置
   需在 Unity 中按真实手柄模型对齐。左右手柄均已按实拍重画为白握把黑圆盘风格。
8. 本轮为位图产出，未提供分层 PSD；FBX 实体模型不在生图交付范围。
