# Bilingual System UI font

Noto Sans CJK SC Regular is provided under the SIL Open Font License 1.1.
The upstream license is included in `OFL.txt`; keep it with the font when distributing this project.

Official source:
- https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
- https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE

`NotoSansCJKsc-Regular SDF.asset` is generated by Unity's TMP APIs, with a
dynamic 1024 x 1024 SDF atlas, multi-atlas support, and embedded source font data.
Current and common future English/Chinese UI characters are prewarmed. Additional
supported characters can be added dynamically; the entire CJK repertoire is not
baked into one atlas.

To regenerate/configure the Main Menu, use:
**Tools > System UI > Configure Chinese Menu Font** (outside Play Mode).
Save any pending MainMenu edits first. The utility updates only the three MainMenu
text labels and their font/material references; it does not change global TMP settings.

For future bilingual UI, assign this TMP font asset directly to its TMP text components.
