# 手绘 UI 素材接入

素材来源：项目根目录 `fire_training_ui_v01/03_png`。原交付文件保留，Unity 使用 `Assets/Resources/FireTrainingUI` 中的副本。预览与概念图没有用作可点击界面背景，也没有把概念图里的房间自动转换成三维模型。

## 查看

打开 MainMenu 或 CampusTraining 场景，进入 Play。界面样式在场景加载和动态教学界面创建时自动应用；编辑模式下原场景仍可能显示原来的底板。无需手动拖拽资源或重新配置按钮功能。

## 已接入

- 主菜单终端外壳、标题布局、开始与退出按钮。
- 暂停、成功/失败底板及运行时生成的结算报告与四页明细。
- 菜单按钮普通、射线指向、按下和禁用外观。
- 课程大卡/短卡、教学提示、任务标签/夹板、物件提示和通知。
- 教室黑板左右手柄图片、教学卡中的手柄图片与程序控制高亮。
- 地图外框与玩家方向箭头，真实地图几何、房号与定位继续由程序生成。
- 血条填充/槽、阅读进度；烟雾等危险警告卡及救援通知卡。
- 浅色纸张使用深色文字与深色任务状态文字；保留可变的双语文案、数值及进度。

并非每个交付图标都需要显示。未使用的装饰、HUD 外壳和图标仍保留在资源目录内，可供后续布局调整。没有新增三维值班室、台灯和桌子模型。

## 验证

Unity 2022.3.62f3 编译及现有教学回归检查：389 项通过。覆盖教学、地图/任务展开、暂停、救援提示、结算明细翻页、多次重开、返回菜单及再次开始。修正了地图房号双行文字高度不足，以及退出时界面对象先销毁导致的清理异常。

回归测试同步适配了图片中已绘制的 ABXY 标签和浅色卡片文字颜色；删除了一条与紧随其后的“当前目标”检查矛盾的旧“进行中”文案断言，保留任务发布和通知检查。

最终完整检查日志：`Logs/ui-style-verified.log`；检查明细：`Documentation/LessonChecks.txt`。未进行 Quest 真机的双眼清晰度、射线手感和性能验收。
