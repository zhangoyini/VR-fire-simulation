# 教学 SKIP：只略过说明，保留实操条件

本说明取代之前“所有页面都可以逐页 SKIP”的实现。用户明确要求以原教学流程为基础，避免等待过久，也避免说明尚未读完就自动切页。

- 说明、操作演示和完成说明页：保持显示，玩家自行点击 SKIP 结束本段阅读/演示。没有固定阅读时限。
- 实操页：不显示 SKIP，程序也拒绝 RequestAdvance 跳过实操。看向四周、看手/抬手、实际暂停/继续、到达落点、开窗、按按钮、拿起书、放回书、打开/收起地图与任务栏、到达门口等仍由实际动作推进。
- 放书重新使用原来的桌面范围、松手与稳定检测，放错位置时仍回到拿书练习；不再用 SKIP 强制放回书。
- 说明提前结束只进入对应操作页，不表示已完成动作。窗口/按钮完成说明仍等待玩家放手后继续。
- 无文字的淡出、面板折叠继续自动完成；暂停练习用真实暂停菜单的“继续”返回。
- 重新开始仍重新进入教学，采用同样的说明/实操规则。
