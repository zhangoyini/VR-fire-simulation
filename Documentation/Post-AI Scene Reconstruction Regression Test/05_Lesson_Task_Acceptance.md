## 对AI改动的理解

- AI对教学或任务流程做了什么：增加了操作教学、开场动画、拿毛巾和打湿毛巾的任务，还加入了路线提示、二层避难区呼叫和结束总结。
- 与原来功能有什么不同：新版的教学顺序更完整，开场结束后恢复操作，玩家需要用手柄推门；下楼和到达终点在同一个场景中完成，减少了场景切换。
- 我认为需要保留或修改的内容：保留教学提示、推门和终点总结；补充轮椅同学支线，让总结能显示实际完成的任务。
- 判断原因：这些改动能帮助玩家理解操作和逃生过程。
